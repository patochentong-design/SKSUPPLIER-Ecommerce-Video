# AGENTS.md — SKSUPPLIER Video Repository

## Primary instruction
For SKSUPPLIER ecommerce video work, always read and follow:
`.agents/skills/sksupplier-ecommerce-video/SKILL.md`

Also use the official Remotion skill/instructions available in the development environment for implementation details.

## Workflow
1. Read the supplied product brief.
2. Validate all supplied product facts.
3. Inspect real product assets.
4. Create/update the Remotion composition.
5. Generate a preview first.
6. STOP and request approval before batch/final renders unless the user explicitly approved rendering.
7. After approval, render requested formats.
8. Report changed files and output filenames.

## Safety / accuracy
- Never invent product specifications, pricing, MOQ, stock, flavors, colors, certifications, or claims.
- Never alter the physical design of supplied products.
- Never overwrite original product assets.
- Keep source assets separate from generated outputs.

# SKSUPPLIER Ecommerce Video Skill V1.0

A project-level AI coding skill for creating consistent SKSUPPLIER ecommerce product videos with Remotion.

## What this package does
- Defines SKSUPPLIER video design and product-accuracy rules.
- Provides a reusable 15-second storyboard.
- Provides a Blinkers Flip 2G example brief.
- Provides a recommended Remotion project structure.
- Enforces preview-first workflow before final rendering.

## Recommended use
Use together with the official Remotion skill:
https://github.com/remotion-dev/skills

Copy this package into your private video repository, then ask Codex to read `AGENTS.md` and use `.agents/skills/sksupplier-ecommerce-video/SKILL.md`.

## Important
Product images are source-of-truth assets. Do not redraw, distort, recolor, or invent physical product features.
